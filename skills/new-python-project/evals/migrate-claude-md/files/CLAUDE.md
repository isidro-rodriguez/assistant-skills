# CLAUDE.md

## Language
- Code in English. Docstrings, comments, README and commits in Spanish.
- User-facing messages are gettext msgids in English wrapped in `_()`; Spanish lives in `src/tasa/locales/es.po`. Never hardcode Spanish in messages.

## Tools
Use uv, never pip. `uv run ruff format .`, `uv run ruff check .`, `uv run ty check`, `uv run pytest`.

## Agent workflow
1. Read README, pyproject and tests before changing.
2. Smallest change; no unrelated refactors.
3. Run the quality commands before finishing.

## Code rules
- PEP 8, strict type hints, Google docstrings.
- Money is always `Decimal`, never `float`; round with ROUND_HALF_EVEN only at presentation.

## Tests
- pytest in tests/, must pass on Linux and Windows.
- Valuation fixtures in `tests/fixtures/*.json` are generated by `scripts/gen_fixtures.py`; never edit them by hand.

## Commits
- Conventional Commits in Spanish. Commit directly when checks pass; never push.

## Releases
- Bump version in pyproject, update CHANGELOG (Keep a Changelog), uv lock, `chore: bump versión a X.Y.Z`.
- Publishing: push a `vX.Y.Z` tag; release.yml builds the wheel and uploads to PyPI.
